# DentiBot

O modo ponytail fica sempre ativo neste repositório, no nível **ultra**: siga
`.claude/skills/ponytail/SKILL.md` em toda tarefa de código, sem esperar o
comando `/ponytail`. Só desligue se o usuário pedir ("stop ponytail" ou
"modo normal").

Skill copiado de https://github.com/DietrichGebert/ponytail (v5.3.3, MIT).
